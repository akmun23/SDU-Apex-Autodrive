Practice raceline sketcher

Shape the line directly on the map. This edits a separate candidate; the source CSV is never overwritten.

1 · Load the three inputs

Use the practice map PGM/YAML and whichever line you want as the starting geometry (for example, v300). Files stay in your browser.

2 · Shape the candidate

In add mode, click where you want the line to move. The editor finds the nearest point on the current path and blends a smooth local displacement. Drag pink handles to refine it. Double-click a handle to remove it. Scroll to zoom; middle/right-drag to pan; press Esc to leave add mode.

3 · Check and export

Load a map, metadata, and path to begin.

The footprint check uses the 0.510 × 0.273 m body rectangle plus 5 cm, and conservatively treats unknown map cells as blocked. Export recalculates path length, heading, curvature, and map ray distances. Existing speed/acceleration columns are copied as references, not re-optimized.
